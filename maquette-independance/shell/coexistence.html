Maquette — coexistence de deux versions du socle

L'équipe filtres a migré vers le socle 2.0, l'équipe tableau est restée en 1.0. La carte d'import permet aux deux de cohabiter, sans recompilation et sans négociation. Cliquez un filtre, puis regardez le nombre d'abonnés retourné et l'identifiant de socle affiché par chaque fragment.

      Coexistence de versions et état partagé sont antagonistes. Ce
      n'est pas un défaut de la carte d'import ni du socle : c'est la sémantique des
      modules ES. Deux URL distinctes produisent deux instances distinctes, même quand
      le code est identique au caractère près — et c'est le cas ici, les deux versions
      du socle ne diffèrent que par leur numéro. Aucune exception n'est levée, aucun
      avertissement n'est émis. Le message est simplement perdu.
